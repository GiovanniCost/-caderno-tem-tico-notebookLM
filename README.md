# -caderno-tem-tico-notebookLM
Este projeto tem como objetivo aplicar a metodologia BESST e os pilares da Carteira Previdenciária de Luiz Barsi em um caderno temático no NotebookLM. A ideia é criar um “segundo cérebro” para investidores iniciantes, ensinando como transformar ações em uma fonte de renda mensal para aposentadoria, com disciplina e visão de longo prazo.
